# Responsive Demo Skill

When you need responsive classes or inline styles, use `@trunkjs/responsive` syntax directly: `-md:x` (`< md`), `md:x` (`>= md`), `md-xl:x` (`>= md && < xl`) or `style-md="..."`; for anything unclear, read [`.ai-usage-info.md`](.ai-usage-info.md), and use [`REFERENCE-SKILL.md`](./REFERENCE-SKILL.md) when creating a full skill.
