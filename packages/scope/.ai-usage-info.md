# @trunkjs/scope

## Zweck

Starter-Paket für neue Scope-bezogene Funktionen.

Aktuell ist das Paket bewusst minimal aufgebaut und enthält nur:
- einen kleinen Einstiegspunkt
- eine Demo-Datei
- die Basis-Konfiguration für Build und Demo-Viewer

## Import

```ts
import { createScopeDemoMessage } from '@trunkjs/scope';
```

## Beispiel

```ts
import { createScopeDemoMessage } from '@trunkjs/scope';

const message = createScopeDemoMessage('Scope');
console.log(message);
```

## Agent-Hinweise

- Das Paket ist aktuell ein Scaffold und kann inkrementell erweitert werden.
- Neue öffentliche API über `src/index.ts` exportieren.
- Weitere Demos unter `demo/*.demo.ts` anlegen.
