# @trunkjs/scope

## Zweck

Starter-Paket für neue Scope-bezogene Funktionen.

Aktuell ist das Paket bewusst minimal aufgebaut und enthält nur:
- einen kleinen Einstiegspunkt
- eine Demo-Datei
- die Basis-Konfiguration für Build und Demo-Viewer

## Import

```ts
import { createScopeDemoMessage } from '@trunkjs/scope';
```

## Beispiel

```ts
import { createScopeDemoMessage } from '@trunkjs/scope';

const message = createScopeDemoMessage('Scope');
console.log(message);
```

## Scope-Typen

In `src/Scope/scope-types.ts` sind die Runtime-Typen für Scopes beschrieben.
Wichtige Konventionen:

```ts
$scope.name.$value;
$scope.adresse.$value;
$scope.mitarbeiter.$value;
```

- `TScopeValue` nutzt `$value` für den eigentlichen Value.
- `TScope` nutzt `$value` für das gesamte darunterliegende Objekt.
- `TScopeArray` nutzt `$value` für das gesamte darunterliegende Array.
