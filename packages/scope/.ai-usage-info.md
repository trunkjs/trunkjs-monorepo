# @trunkjs/scope

## Zweck

Starter-Paket für neue Scope-bezogene Funktionen.

Aktuell enthält das Paket:
- typisierte Scope-Definitionen
- eine Proxy-basierte Runtime für Scopes, Values und Arrays
- eine kleine Demo-Datei
- Basis-Konfiguration für Build und Demo-Viewer

## Import

```ts
import {
  createScope,
  createRuntimeEntry,
  defineArray,
  defineScope,
  ScopeArrayRuntime,
  ScopeProxyRuntime,
  ScopeValueRuntime,
} from '@trunkjs/scope';
```

## Beispiel

```ts
import { createScope, defineArray, defineScope } from '@trunkjs/scope';

const $scope = createScope({
  name: {
    defaultValue: 'Max',
  },
  firma: defineScope({
    ort: {
      defaultValue: 'Berlin',
    },
  }),
  mitarbeiter: defineArray({
    name: {
      defaultValue: 'Anna',
    },
  }),
});

$scope.name.$value = 'Moritz';
$scope.firma.ort.$value = 'Hamburg';
$scope.mitarbeiter[0].name.$value = 'Lisa';
```

## Anpassbarer Value-Container

`createScope(...)` akzeptiert optional Runtime-Optionen.
Darüber kann ein eigener Value-Container gesetzt werden.

```ts
import { createScope, ScopeValueRuntime } from '@trunkjs/scope';

class FormLikeValue extends ScopeValueRuntime<any, any, any> {
  get value() {
    return this.$value;
  }

  set value(next) {
    this.$value = next;
  }
}

const $scope = createScope(
  {
    name: {
      defaultValue: 'Max',
    },
  },
  {
    createValue: (name, definition, scope, root) => new FormLikeValue(name, definition, scope, root),
  },
);

$scope.name.value = 'Moritz';
```

## Metadata via `$meta`

Definitionen können optional `$meta` als Objekt oder Callback bekommen.
Beim Runtime-Zugriff liefert `$meta` immer einen Snapshot mit `{ meta, value }`.
Bei Scopes und Arrays wird dieser Snapshot rekursiv aufgebaut.

```ts
const $scope = createScope({
  $meta: { section: 'person' },
  name: {
    defaultValue: 'Max',
    $meta: (value, scope) => ({
      length: value.length,
      current: scope.name.$value,
    }),
  },
  tags: defineArray({
    label: {
      defaultValue: 'starter',
      $meta: { label: 'Tag label' },
    },
  }),
});

$scope.tags.first().label.$value = 'alpha';

$scope.name.$meta;
// => { meta: { length: 3, current: 'Max' }, value: 'Max' }

$scope.$meta;
// => {
//   meta: {
//     $self: { section: 'person' },
//     name: { meta: { length: 3, current: 'Max' }, value: 'Max' },
//     tags: {
//       meta: {
//         $self: {},
//         items: [
//           {
//             meta: {
//               $self: {},
//               label: { meta: { label: 'Tag label' }, value: 'alpha' },
//             },
//             value: { label: 'alpha' },
//           },
//         ],
//       },
//       value: [{ label: 'alpha' }],
//     },
//   },
//   value: {
//     name: 'Max',
//     tags: [{ label: 'alpha' }],
//   },
// }
```

## Scope-Typen

In `src/Scope/scope-types.ts` sind die Runtime-Typen für Scopes beschrieben.
Wichtige Konventionen:

```ts
$scope.name.$value;
$scope.adresse.$value;
$scope.mitarbeiter.$value;
```

- `TScopeValue` und `TBoundScopeValue` nutzen `$value` für den eigentlichen Value.
- `TScope` nutzt `$value` für das gesamte darunterliegende Objekt.
- `TScopeArray` nutzt `$value` für das gesamte darunterliegende Array.
- `TScope`, `TScopeValue` und `TScopeArray` haben zusätzlich ein generisch abgeleitetes `$root`.

## Agent-Hinweise

- Öffentliche API über `src/index.ts` exportieren.
- Runtime nutzt Proxy-basierte Scope-Objekte.
- Beispiele für Scope-Nutzung liegen in `src/Scope/scope-types-demo.ts`.
- Tests sind bewusst sparsam gehalten: kleine Unit-Tests pro Teilfunktion, größere Flows als Integrationstest.
