# @trunkjs/content-pane — agent reference

Turns flat Markdown-rendered HTML into nested sections, then replaces sections via `layout`.

**Creating a skill that uses ContentPane?** Copy/adapt `demo-skill/SKILL.md`; it is the canonical compact skill template and should be used as the source for ContentPane rules/examples.

## `i` tree index

`smaller = outer`, `larger = deeper`. Defaults: `h1=2`, `h2=2`, `h3=3`, `h4=4`, `h5=5`, `h6=6`. A heading with explicit `i` uses that value. `hr[layout]` without explicit `i` uses the last heading/fixed `i + 0.5`; plain `<hr>` is ignored.

Markdown normally sets attributes as passdown attributes directly after the element:

```md
## Products
{: layout="page-section" section-class="wide"}
```

Equivalent source HTML:

```html
<h2 layout="page-section" section-class="wide">Products</h2>
```

## `layout` syntax

```text
layout="component"       inferred heading i; create section
layout="3;component"     i=3; create section
layout="+3;"             reuse/append to existing section at i=3
layout="-3;"             create no section; keep element in current container
layout="component#id.cls[attr=value]"  replacement selector
```

Prefer `layout` on the heading owning the section. Use `<hr layout="...">` only for an extra wrapper between heading levels.

Example:

```md
## Products
{: layout="page-section"}

---
{: layout="card-grid"}

### A
### B
```

Tree: `page-section(i=2) > card-grid(i=2.5) > h3 sections(i=3)`.

Before layout replacement, conceptually:

```html
<section layout="page-section"><h2>Products</h2><section layout="card-grid"><hr hidden><section><h3>A</h3></section><section><h3>B</h3></section></section></section>
```

After `applyLayout()`:

```html
<page-section><h2>Products</h2><card-grid><hr hidden><section><h3>A</h3></section><section><h3>B</h3></section></card-grid></page-section>
```

`section-*` attributes configure the generated section and lose the prefix, e.g. `section-id="x"`, `section-class="wide"`, `section-style="..."`. Classes named `section-*` are likewise moved to the section without the prefix.
