# @trunkjs/content-pane — agent reference

Turns flat Markdown-rendered HTML into nested sections, then replaces sections via `layout`. For ContentPane skills copy/adapt `demo-skill/SKILL.md` as canonical rules/template.

## Default

Use headings as the tree; **omit `i` when inferable** and put `layout` on the owning heading. `h1/h2=2`, `h3=3`, `h4=4`, ... . Markdown passdown attributes follow the element: `{: layout="page-section" section-class="wide"}`.

Use HR only for layout control without its own heading (e.g. a grid/background around several headed children). `hr[layout]` without `i` opens at last fixed `i + 0.5`; plain HR is ignored. Explicit `i` is exceptional.

```text
layout="x"       inferred heading i; new section (preferred)
layout="3;x"     explicit i=3; new section
layout="=3;"     reuse/append existing i=3 section
layout="!;"      no section for this element
layout="/3;"     close i=3 and all deeper open levels (HR control)
layout="/;"      close current open level (HR control)
```

Legacy `+i`=`=i`, `-i`=`!i`. `section-*` configures the generated section and loses its prefix. Selector: `layout="card-box#id.cls[attr=value]"`.

```md
---
{: layout="1;page-background"}

## Intro
## Features

---
{: layout="/1;"}

## Outside
```

Result: `<page-background>...Intro...Features...</page-background><section><h2>Outside</h2></section>`; the closing HR is a control marker and is removed.

## Sub-layout selector variables

`SubLayoutApplyMixin` evaluates the `|`-separated alternatives in a slot's `data-query` from left to right and uses all matches from the first successful alternative. An alternative may reference a CSS custom property on the host:

```html
<slot name="top" data-query="@var(--top-selector) | :scope > .top"></slot>
```

- `@var(--name)` must be a complete alternative.
- A missing, empty, or non-matching variable continues with the next alternative.
- A malformed `@var(...)` expression or an invalid resolved selector throws a contextual error.
- The variable value is one selector string; use a comma-separated selector list to select several patterns. Do not quote the value in CSS.
- Variable matches are assigned after built-in selector matches, so theme overrides do not depend on shadow-slot order.
- Resolution runs in `firstUpdated`; changing the variable later does not reassign existing content.
